# ChannelHub AI Repository Context

## Purpose

Dokumen ini menjadi konteks wajib bagi AI assistant yang bekerja pada repository ChannelHub.

## Before Making Changes

AI wajib:

1. Membaca README.md.
2. Membaca seluruh dokumen terkait perubahan.
3. Memastikan tidak ada konsep duplikat.
4. Mengikuti struktur folder yang sudah ada.
5. Menjaga konsistensi terminologi.
6. Membuat ADR untuk keputusan arsitektur besar.

## Development Philosophy

ChannelHub dibangun dengan prinsip:

- Documentation first.
- Architecture first.
- Configuration driven.
- Modular design.
- Microservice ready.

## Prohibited Actions

Jangan:

- Membuat file tanpa alasan yang jelas.
- Mengubah keputusan arsitektur tanpa dokumentasi.
- Mengabaikan dokumen existing.
- Membuat asumsi bisnis tanpa pencatatan.
