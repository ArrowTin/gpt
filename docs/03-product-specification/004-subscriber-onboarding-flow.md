# ChannelHub Subscriber Onboarding Flow

## Purpose

Mendefinisikan perjalanan pengguna baru sejak registrasi sampai dapat menggunakan platform.

---

# 1. Registration

Flow:

```
User Register
      |
      v
Email Verification
      |
      v
Create Organization
```

---

# 2. Organization Setup

User mengisi:

- Organization name.
- Business type.
- Contact information.
- Subscription selection.

---

# 3. Property Setup

Flow:

```
Create Property
      |
Create Room
      |
Setup Inventory
      |
Setup Pricing
```

---

# 4. User Invitation

Owner dapat:

- Invite administrator.
- Assign role.
- Configure permission.

---

# 5. OTA Connection

Flow:

```
Select OTA
      |
Connect Account
      |
Mapping
      |
Synchronization
```

---

# 6. Subscription Activation

Setelah pembayaran:

- Subscription active.
- Feature entitlement aktif.
- Invoice tersedia.

---

# 7. Dashboard Access

User melihat menu sesuai:

- Role.
- Permission.
- Subscription plan.

---

# 8. First Success Goal

Pengguna berhasil:

- Membuat property.
- Menghubungkan channel.
- Menerima reservation.
- Melihat laporan.
