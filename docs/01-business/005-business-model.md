# ChannelHub Business Model

## Purpose

Dokumen ini mendefinisikan model bisnis ChannelHub sebagai platform hospitality ecosystem.

## Business Position

ChannelHub bukan hanya OTA connector.

ChannelHub adalah:

```
Hospitality Operating Platform
        +
OTA Distribution Layer
        +
Property Management Ecosystem
```

ChannelHub menjadi pusat orkestrasi antara properti, OTA, partner teknologi, dan pengguna bisnis.

---

# 1. Customer Segment

Target pengguna:

- Homestay.
- Hotel kecil dan menengah.
- Villa.
- Resort.
- Property manager.
- Enterprise hospitality.

---

# 2. Value Proposition

Nilai utama ChannelHub:

## Operational Simplification

Pengguna cukup mengelola:

- Property.
- Room.
- Inventory.
- Price.
- OTA channel.

Sistem menangani kompleksitas:

- API integration.
- Synchronization.
- Retry mechanism.
- Webhook processing.
- Error handling.

## Distribution Management

Satu properti dapat terhubung dengan banyak channel:

- Booking.com.
- Agoda.
- Traveloka.
- Airbnb.
- Expedia.
- Tiket.com.

## Data Centralization

ChannelHub menjadi sumber data operasional:

- Reservation.
- Revenue.
- Inventory.
- Channel performance.

---

# 3. Revenue Model Overview

Pendapatan ChannelHub berasal dari beberapa sumber:

## SaaS Subscription

Pengguna membayar akses platform secara berkala.

Contoh:

- Monthly plan.
- Yearly plan.
- Enterprise plan.

## Usage Based Service

Biaya berdasarkan penggunaan tertentu.

Contoh:

- Jumlah property.
- Jumlah kamar.
- Volume sinkronisasi.
- Premium processing.

## Premium Feature

Fitur tambahan berbayar:

- Advanced analytics.
- Automation.
- AI assistant.
- Marketing tools.
- Custom report.

## Ecosystem Revenue

Pendapatan dari aktivitas ecosystem:

- Partner integration.
- Revenue sharing.
- Marketplace service.

---

# 4. Business Flow

```
Subscriber
    |
    | Subscription Payment
    v
ChannelHub
    |
    | Platform Service
    v
Property Operation
    |
    | Distribution
    v
OTA Ecosystem
```

---

# 5. Strategic Principle

ChannelHub tidak bergantung hanya pada satu sumber pendapatan.

Strategi:

- Subscription menjadi pendapatan utama.
- Premium feature meningkatkan ARPU.
- Ecosystem revenue menjadi pertumbuhan jangka panjang.

---

# 6. Design Rule

Model bisnis harus fleksibel dan dapat dikonfigurasi.

Pricing, subscription plan, feature access, dan billing rule tidak boleh hardcoded.

Sistem harus mendukung perubahan bisnis melalui konfigurasi.
