# ChannelHub Folder Structure Standard Blueprint

## Purpose

Menetapkan standar folder agar seluruh agent dan developer mengikuti struktur yang sama.

---

# Root Structure

```
channelhub/
 |
 +-- apps/
 +-- services/
 +-- packages/
 +-- database/
 +-- infrastructure/
 +-- docs/
```

---

# Backend Structure

```
backend/
 |
 +-- modules/
 +-- common/
 +-- config/
 +-- database/
 +-- tests/
```

---

# Frontend Structure

```
frontend/
 |
 +-- app/
 +-- components/
 +-- features/
 +-- services/
 +-- tests/
```

---

# Rule

Struktur folder harus:

- Mudah ditemukan AI agent.
- Konsisten.
- Tidak membuat duplikasi.
