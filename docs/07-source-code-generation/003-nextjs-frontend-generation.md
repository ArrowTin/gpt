# ChannelHub Next.js Frontend Generation Blueprint

## Purpose

Menjadi panduan AI untuk membangun frontend foundation.

---

# 1. Technology

Target:

- Next.js.
- TypeScript.
- Component based architecture.

---

# 2. Structure Direction

```
app
components
features
services
hooks
lib
types
```

---

# 3. AI Generation Rule

AI wajib:

- Membuat reusable component.
- Menggunakan API abstraction.
- Memisahkan business logic.
- Mengikuti permission system.

---

# 4. Authentication Integration

Frontend harus siap:

- Login state.
- Session handling.
- Protected route.
- Permission rendering.

---

# 5. Validation

Selesai jika:

- Application build.
- API connection berjalan.
- Routing siap.
