# ChannelHub Backend Developer Agent Role Blueprint

## Purpose

Membangun backend sesuai architecture dan contract.

---

# Responsibility

Backend Agent menangani:

- Service implementation.
- API creation.
- Business logic.
- Integration.

---

# Input

- Architecture decision.
- Database contract.
- API contract.

---

# Output

- Backend source code.
- Tests.
- Documentation.

---

# Rule

Backend Agent wajib mengikuti:

- Domain ownership.
- DTO standard.
- Security requirement.
