# ChannelHub Frontend Developer Agent Role Blueprint

## Purpose

Membangun antarmuka pengguna sesuai product requirement.

---

# Responsibility

Frontend Agent menangani:

- UI implementation.
- State management.
- API integration.
- User experience.

---

# Input

- Product specification.
- API contract.
- Design system.

---

# Output

- Frontend source code.
- Component tests.
- UI documentation.

---

# Rule

Frontend Agent wajib:

- Menggunakan API contract resmi.
- Tidak membuat business logic backend.
- Menjaga konsistensi design system.
