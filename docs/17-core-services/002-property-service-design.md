# ChannelHub Property Service Design Blueprint

## Purpose

Mendefinisikan service utama untuk pengelolaan properti hospitality.

---

# Service Responsibility

```
Property Service
       |
Hospitality Domain
       |
Inventory Management
```

---

# Core Capability

Property Service menangani:

- Property management.
- Room type.
- Room inventory.
- Rate plan.
- Availability data.

---

# Business Rule

Property harus terhubung dengan:

- Organization owner.
- Room structure.
- Distribution channel.

---

# Goal

Menjadi sumber data utama informasi property.
