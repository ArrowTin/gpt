# ChannelHub AI Review Checklist

## Purpose

Checklist validasi sebelum menerima hasil implementasi dari AI.

---

# Architecture Review

- Apakah mengikuti blueprint?
- Apakah boundary service tetap benar?
- Apakah dependency sesuai?

---

# Code Review

- Naming konsisten.
- Struktur folder sesuai.
- Tidak ada hardcode.
- Error handling tersedia.

---

# Security Review

- Authentication benar.
- Authorization diterapkan.
- Secret aman.
- Input tervalidasi.

---

# Testing Review

- Unit test tersedia.
- Integration test tersedia jika diperlukan.
- Failure scenario diuji.

---

# Documentation Review

- README update.
- API document update.
- Decision record tersedia.
