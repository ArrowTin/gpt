# ChannelHub Context Management System

## Purpose

Menjaga kesinambungan AI development agar setiap perubahan tetap sesuai keputusan sebelumnya.

---

# 1. Context Layers

```
Project Context
      |
Architecture Context
      |
Module Context
      |
Task Context
```

---

# 2. Project Context

Berisi:

- Vision.
- Business goal.
- Technology stack.
- Architecture principle.

---

# 3. Architecture Context

Berisi:

- Service boundary.
- Database ownership.
- API contract.
- Security rule.

---

# 4. Module Context

Setiap module memiliki:

- Requirement.
- Dependency.
- Related files.
- Test scenario.

---

# 5. Session Handoff

Setiap akhir pekerjaan harus mencatat:

- Completed.
- Changed.
- Pending.
- Next step.

---

# 6. Goal

AI dapat melanjutkan pembangunan tanpa kehilangan keputusan sebelumnya.
