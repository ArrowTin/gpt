# ChannelHub AI Coding Principle Blueprint

## Purpose

Mendefinisikan aturan penggunaan AI sebagai partner development agar hasil coding tetap mengikuti arsitektur yang telah disepakati.

---

# 1. AI Role

AI berfungsi sebagai:

- Architecture assistant.
- Implementation assistant.
- Code reviewer.
- Documentation maintainer.

AI bukan pengambil keputusan arsitektur tanpa validasi.

---

# 2. Development Rule

AI wajib:

- Membaca blueprint sebelum membuat kode.
- Mengikuti struktur repository.
- Menggunakan pattern yang sudah ditentukan.
- Menjaga backward compatibility.

---

# 3. Forbidden Behavior

AI tidak boleh:

- Membuat service baru tanpa alasan.
- Mengubah arsitektur utama secara sepihak.
- Membuat konfigurasi hardcode.
- Mengabaikan security standard.

---

# 4. Implementation Cycle

```
Understand
   |
Plan
   |
Implement
   |
Test
   |
Review
   |
Document
```

---

# 5. Context Priority

Prioritas referensi:

1. Architecture blueprint.
2. Technical standard.
3. Existing code.
4. New requirement.
