# ChannelHub Vibe Code Prompt Library

## Purpose

Menyediakan pola prompt yang konsisten untuk pembangunan sistem.

---

# 1. Backend Module Prompt

Template:

```
Baca architecture blueprint.
Buat module sesuai service boundary.
Ikuti folder standard.
Tambahkan validation dan testing.
Update documentation.
```

---

# 2. Frontend Feature Prompt

Template:

```
Implementasikan feature berdasarkan UI architecture.
Gunakan permission driven rendering.
Buat component reusable.
Tambahkan state dan API integration.
```

---

# 3. Database Prompt

Template:

```
Buat schema berdasarkan ownership service.
Tambahkan migration.
Tambahkan index.
Dokumentasikan perubahan.
```

---

# 4. API Prompt

Template:

```
Buat API mengikuti contract standard.
Tambahkan validation.
Dokumentasikan OpenAPI.
Tambahkan error handling.
```

---

# 5. Deployment Prompt

Template:

```
Implementasikan deployment mengikuti infrastructure blueprint.
Pastikan monitoring dan security aktif.
```
