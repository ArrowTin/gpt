# ChannelHub Next.js Bootstrap Blueprint

## Purpose

Menetapkan fondasi aplikasi frontend menggunakan Next.js.

---

# Project Structure

```
frontend/
 |
 +-- app/
 +-- components/
 +-- features/
 +-- hooks/
 +-- services/
 +-- stores/
 +-- styles/
 +-- utils/
```

---

# Architecture Principle

Frontend menggunakan:

- Feature based structure.
- Reusable component.
- Separated API service layer.
- Scalable routing.

---

# Goal

Membentuk aplikasi frontend production-ready.
