# Development Ready Checklist

## Purpose

Memastikan increment siap lanjut ke review/test.

## Architecture

- [ ] Selaras docs phase terkait dan ADR Accepted
- [ ] Service boundary tidak dilanggar
- [ ] Tenant context dipertimbangkan

## Implementation

- [ ] Scope micro-prompt tidak melebar ke modul lain
- [ ] Error handling & validation sesuai standards/
- [ ] Tidak ada secret / credential di repo

## Documentation

- [ ] Doc terkait diperbarui jika behavior berubah
- [ ] Cross-link ke adr/standards/prompts jika perlu
